SOS Oil Analysis - Overview

Program Preventive Maintenance diagnostik yang berfokus pada analisis laboratorium sampel pelumasan (oil)

SOS Kompartemen List

—

Filter:
Status kesehatan oli per equipment dan kompartemen
Peringkat Asset ID Model Status Kompartemen Lifetime Comp HM Unit HM Oil Na Fe Cu Si Al Pb PQI V100 Tanggal Aksi

Status ditentukan dari parameter yang melewati threshold (Normal/Caution/Critical). Criticality = Severity(45%) + Evidence(30%) + Trend(25%), dihitung pada window 4000 jam SMR/HM terakhir. Lifetime Comp diambil dari data Lifetime (Template Nomor Lambung - Umur Comp - Section). Section dapat disaring melalui dropdown "Semua Section" di baris filter. Nilai kolom parameter (Fe, Cu, Si, PQI, V100) dapat dipilih: Sampel Terbaru, Rata-rata (window 4000 jam terakhir), atau Terburuk (sampel dengan severity tertinggi pada window 4000 jam terakhir). Bila HM tidak tersedia, sistem jatuh ke 5 sampel terakhir. Klik baris untuk detail.

Tema tampilan & ambang batas (threshold) parameter

Pilih tema tampilan. Pilihan tersimpan otomatis di browser.

Ambang batas VHMS per keluarga model (tiap keluarga punya profil & parameter berbeda). Nilai disimpan di browser & langsung dipakai untuk deteksi anomali. Mode: high = makin besar makin bahaya, low = makin kecil makin bahaya.

Threshold default VHMS per keluarga model unit
ParameterWarnCritModeLabel

Threshold per Model Unit (VHMS)

Sebagian parameter berbeda antar model (mis. Fuel Rate/Boost HD785 vs D375A). Override bersifat opsional & parsial: cukup isi parameter yang berbeda — parameter lain otomatis memakai nilai keluarga. Model dicocokkan longgar (mis. "HD785-7" cocok dengan "HD785").

Override threshold VHMS per model unit
ParameterWarnCritModeLabel

Ambang batas SOS per kompartemen. Beberapa parameter memakai batas low (mis. viscositas/TBN — makin rendah makin buruk).

Threshold default SOS per kompartemen
ParameterWarnCritExtremeWarn LowCrit Low

Threshold per Model Unit (SOS)

Ambang batas SOS bisa berbeda antar model untuk kompartemen yang sama (mis. ENGINE HD785 vs PC2000). Override bersifat opsional & parsial — parameter yang tidak diisi memakai nilai kompartemen. Model dicocokkan longgar.

Override threshold SOS per model unit
ParameterWarnCritExtremeWarn LowCrit Low

Status ditentukan dari nilai vs ambang threshold parameter: melewati ambang warn → CAUTION, melewati ambang crit/extreme → CRITICAL. Atur SLA (Target) tiap status di bawah ini (tampil di tabel Suggestion halaman Portofolio).

Daftar status prioritas follow-up dengan target SLA
StatusTarget (SLA)

Filter Umur Komponen menyaring sampel SOS & telemetri VHMS yang terjadi sebelum pemasangan komponen terakhir (dari file Lifetime Unit). Tujuannya: angka keausan dinilai pada umur komponen yang benar — Fe 350 ppm pada komponen 12.000 jam itu normal, pada komponen 200 jam itu kegagalan dini.

Default nonaktif. Saat aktif, angka pada tabel & peringkat memakai sampel komponen sekarang saja. Saklar dapat dimatikan kapan saja.

Bila selisih HM antara sumber sampel & Lifetime melebihi ambang ini, potong dibatalkan (demi keamanan data).

Sampel yang dikecualikan tetap ditampilkan sebagai titik redup (garis putus-putus) agar asal-usul data terlihat — tidak ikut perhitungan.
