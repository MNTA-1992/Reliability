Model Terdeteksi:

SOS Equipment — Status per Kompartemen

—

Filter:
Rangking Status Asset ID Model Kompartemen HM Unit HM Oil Na Fe Cu Si Al PQI V100 MPRS Tanggal Aksi

Formula: MPRS = Σ(weight × severity) × compound factor — menentukan Status (Normal/Monitor/Caution/Critical). Criticality = Severity(45%) + Evidence(30%) + Trend(25%), dihitung pada window 4000 jam SMR/HM terakhir. Nilai kolom parameter (Fe, Cu, Si, PQI, V100) dapat dipilih: Sampel Terbaru, Rata-rata (window 4000 jam terakhir), atau Terburuk (sampel dengan severity tertinggi pada window 4000 jam terakhir). Bila HM tidak tersedia, sistem jatuh ke 5 sampel terakhir. Klik baris untuk detail.

Tema tampilan & ambang batas (threshold) parameter

Pilih tema tampilan. Pilihan tersimpan otomatis di browser.

Ambang batas VHMS per keluarga model (tiap keluarga punya profil & parameter berbeda). Nilai disimpan di browser & langsung dipakai untuk deteksi anomali. Mode: high = makin besar makin bahaya, low = makin kecil makin bahaya.

ParameterWarnCritModeLabel

Threshold per Model Unit (VHMS)

Sebagian parameter berbeda antar model (mis. Fuel Rate/Boost HD785 vs D375A). Override bersifat opsional & parsial: cukup isi parameter yang berbeda — parameter lain otomatis memakai nilai keluarga. Model dicocokkan longgar (mis. "HD785-7" cocok dengan "HD785").

ParameterWarnCritModeLabel

Ambang batas SOS per kompartemen. Beberapa parameter memakai batas low (mis. viscositas/TBN — makin rendah makin buruk).

ParameterWarnCritExtremeWarn LowCrit Low

Threshold per Model Unit (SOS)

Ambang batas SOS bisa berbeda antar model untuk kompartemen yang sama (mis. ENGINE HD785 vs PC2000). Override bersifat opsional & parsial — parameter yang tidak diisi memakai nilai kompartemen. Model dicocokkan longgar.

ParameterWarnCritExtremeWarn LowCrit Low

Status ditentukan dari nilai vs ambang threshold parameter: melewati ambang warning → WARNING, melewati ambang critical → CRITICAL. Atur SLA (Target) tiap status di bawah ini (tampil di tabel Suggestion halaman Portofolio).
